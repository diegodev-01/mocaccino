# ☕ Mocaccino

**Mocaccino** is a tool that allows multiple users to import their personal schedules from Google Calendar and compare them, making it easy to coordinate meetings, group classes, study sessions, events, and more.

## Main Features

- Secure import of personal calendars using OAuth 2.0
- Cross-user schedules availability comparison
- Clean and intuitive interface for easy coordination
- Built with modern technologies

## Tecnologies Used

- **Design:** [Figma](https://www.figma.com/design/vBeYnL7BikPzgqTtvngeEw/Mocaccino?node-id=0-1&p=f&t=c6cCkzeXlRXh4ZIt-0)
- **Framework:** [Astro](astro.build)
- **Language:** [TypeScript](www.typescriptlang.org)
- **API:** [GoogleCalendarAPI](https://developers.google.com/workspace/calendar/api)
